# БухКальк — бухгалтерский калькулятор

## Возможности
- Главный экран со сводкой доходов, расходов, результата и расчётного НДС.
- Добавление доходов и расходов с датой, категорией, описанием и ставкой НДС.
- Калькулятор начисления или выделения НДС.
- Экспорт отчётов в CSV и Excel (.xlsx), включая лист со сводкой.
- Меню, панель инструментов, перетаскиваемые окна с жёлто-белыми заголовками, панель окон.
- Локальная SQLite-база; записи хранятся в `~/.buh_calculator/`.

## Запуск
Рекомендуется Python 3.10+ с Tk (на Arch: `sudo pacman -S tk`).

```bash
/usr/bin/python3 -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Зависимости
- openpyxl (для Excel-экспорта)

> Это универсальный инструмент учёта и расчётов, а не замена профессиональной бухгалтерской системе. Налоговые ставки и правила зависят от страны и режима налогообложения. Проверяйте отчёты перед использованием в официальной отчётности.
